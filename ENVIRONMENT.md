## Notes

- `SESSION_SECRET` must be at least 32 characters. Rotating it invalidates
  every existing session, so users are signed out.
- `DATABASE_URL` is optional locally because the application falls back to an
  embedded PostgreSQL build (PGlite) under `.data/postgres`. Production must
  set it to a real PostgreSQL server.
- `EMAIL_PROVIDER=log` writes password reset messages to the server log
  instead of sending them. That is acceptable for local work and is not
  acceptable in production, where `EMAIL_PROVIDER_API_KEY` must be set.
- `ML_SERVICE_API_KEY` must match the service's `ML_API_KEY` when the service
  runs with `ML_REQUIRE_API_KEY=true`.
